# 用选择题和判断题检验问答准确率

题库在知识库外保存。每题单独调用网页使用的 `POST /api/v1/ask`，发送题干、选项和作答格式要求。请求使用空白对话历史，参考答案仅供本地评分。程序继续使用已上传的资料、既有检索和引用校验规则。

## 本地运行

先把这份 Word 题库转成每题一条的 JSONL。转换器会保留原题号、段落位置、选项、答键及图片文件，以顺序 ID 区分同号题。判断题统一使用 A 表示正确、B 表示错误。该转换器针对这份题库的编号及答案格式。

```bash
.venv/bin/python scripts/convert_12123_exam.py "/路径/题库.docx" data/local/exams/12123-2026/questions.jsonl
```

启动项目问答服务后，先用少量题目检查接口和评分，再对同一结果文件续跑。例如：

```bash
.venv/bin/python -m transport_law.exam_eval data/local/exams/12123-2026/questions.jsonl output/my-exam/results.jsonl --workers 2 --limit 3
.venv/bin/python -m transport_law.exam_eval data/local/exams/12123-2026/questions.jsonl output/my-exam/results.jsonl --workers 4
```

每次在线问答使用项目所配置的百炼和 DeepSeek 服务，产生相应的 API 用量。默认服务地址为 `http://127.0.0.1:8000/api/v1/ask`，可以用 `--endpoint` 指定本机其他测试实例。

结果按题记录回复、所选答案、状态、引用及检索片段 ID。服务恢复后，用 `--retry-errors` 重试失败项并继续未测题目。用 `--rescore` 可本地重判已保存的回答。重试和重判追加记录，同一 ID 以最后一条为准。另一次独立复测应指定新的结果文件，并记录使用的模型、知识库和检索参数。

## 如何读分数

- **可测试题准确率**用答对题数除以具备题干、有效参考答案和必要输入的题数。服务明确表示证据不足，或回复没有给出可识别结论，都不能得分。
- **已作答正确率**用答对题数除以明确选出答案的题数。同时查看作答率，避免在大量弃答时高估整体表现。
- **调用错误**单列。若有未完成的请求，报告应显示未完成数和当前覆盖情况。
- 命令输出中的 `accuracy` 是答对数除以已尝试题数，只有 `pending` 为零时才是整套可测题的准确率。
- **图片题和残缺题**保留来源及跳过原因。现有接口只接受文本，缺少决定答案的图时不能按原题评分。

评分以原文所附答案为基准。法规版本、题库答案的时效性、回答理由及引用是否支持结论，需要另行核验。

评价实际咨询时，可将公开执法案例改写为当事人的提问。在运行前固定问法、关键事实和评分标准，只将问法发送给服务。评分时对照当时适用的规定和本轮实际引用的原文，记录结论正确、回答不完整、结论错误和依据不足。行政处罚有裁量空间时，核对法定范围和条件，不能要求助手猜中某次执法最终决定的金额。曾用于调整检索或提示词的题目仅用于回归，公开案例的小样本结果也应与题库成绩分别报告。
