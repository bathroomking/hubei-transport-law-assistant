# 湖北交通法律法规资料库

检索整理日期：**2026-11-04**。资料覆盖交通运输执法与公安道路交通管理，两类机关的职权、程序和裁量依据须分别使用。本轮补入交警事故现场判断与普法所需的核心法源。

目前保存 **16 部法规、规章的 1,280 条正文**，另整理湖北公安裁量基准总则 **22 条**、交通管理册 **29 项（79 档）**，连同原上传裁量表的 5 条记录，共 **1,336 条检索记录**。本轮新增 606 条，原上传记录的原文、ID 和出处保持不变。下表年份表示收录版本，不表示已完成独立的现行效力审查。

### 本轮版本和转录说明

- **湖北实施办法有两份官方依据。**省人大底本显示第二次修正（2013 年）；2017 年修改决定第二项仅替换第 56 条第 5 款。构建脚本校验两份原件哈希和被替换原句后机械合并，其他条文不改；第 56 条通过 `supporting_sources` 同时返回修改决定。没有把 2013 年网页标成 2017 年官网重发全文。修改决定的独立公布日期尚未单独核验，因此版本施行日期留空。
- **事故处理程序的 2026 年草案不入库。**检索发现[公安部公开征求意见消息](https://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202605/t20260509_534630.html)，本次未取得正式生效修改文本，仍保存第 146 号令正文。不能把草案关于逃逸责任等修改写进现行条文，后续正式发布需要继续核对。
- **公安裁量使用 2026 年版。**发布通知明确自 2026-01-30 印发之日起施行，同时废止 2023 年版；另核对[2026 年规范性文件清理目录](https://gat.hubei.gov.cn/bmdt/tzgg/202606/t20260629_5966399.shtml)。采用当前通知链接的 236 页附件，物理页码与印刷页码相差 2 页，不混用另一个 237 页副本。
- **交通管理册仅细化行政拘留。**总则第 20 条将罚款、吊销驾驶证等交由相关法律、法规、规章规定。29 个表项各自保留全部档次，不能以此计算罚款、记分或事故责任。其余管理册只归档于原 PDF，不进入本项目检索。
- **原文疑点不擅自纠正。**交通管理册第 6 项“违法行为”和“违法情节”列的“伪造、变造／使用”表述不一致；第 13 项对道路交通安全法第 91 条的款次引用不一致。整理稿和检索记录都保留原文并提示适用前复核。

新增资料解决的是法源缺口。当前仍不识别现场照片/视频，不自动认定车辆性质、违法成立或事故责任，也没有新增交警处罚规则引擎；刑事量刑、检测阈值、鉴定规范及市县特别规定尚需另行补齐。

## 本次特别处理的版本问题

- **道路运输条例使用 2026 年版本。**司法部汇编正文记载 2026-01-30 第六次修订，第 9、22 条已将驾驶人员年龄要求交由国务院交通运输主管部门规定。不能继续从旧表推导“60 周岁”。[第 829 号国务院令修改决定](https://nyncj.gz.gov.cn/attachment/7/7981/7981147/10711032.pdf)记载自 2026-03-20 施行；正文末条的 2004-07-01 是原条例施行日期。配套从业人员规章不在本批全文中，具体年龄问题仍须补充配套依据。
- **湖北水路交通条例使用 2026 年修订全文。**公告及第 73 条记载自 2026-08-01 施行，另与[湖北省人大解读](https://www.hppc.gov.cn/rdgz/dflf/fgjd/2094978763409793025.html)核对修订日期和条数。未把 2021 年旧版放入默认检索。
- **国家和湖北的农村公路条例分别保存。**前者为 2025 年行政法规，后者为本次取得的 2007 年地方性法规文本；效力层级和衔接适用需复核，不能只按网页发布时间替换或宣告废止。
- **公路法征求意见稿不入库。**检索发现了[2026 年修正草案公开征求意见消息](https://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202609/t20260908_539404.html)，本次仍保存 2017 年修正正文，不把草案当作施行文本。原法施行日与修改决定施行日分开记录，未单独核验的日期留空。
- **网页不是 PDF。**网页记录采用法规名称、版本和条号定位，`pdf_page=null`。原 PDF 继续使用真实物理页码。HTML 原始副本和浏览工具提取的网页文本快照在清单中分别标为 `html`、`web_text`，不会混称原始下载文件。

## 文件位置与使用

| 路径 | 用途 |
| --- | --- |
| `data/raw/laws/` | 官方 HTML、网页可见文本快照、原始公安裁量 PDF 及按条/表项整理稿 |
| `data/raw/laws/manifest.json` | 来源、版本、层级、条数、SHA-256、检索主题和效力待核验说明 |
| `data/processed/legal_chunks.jsonl` | 默认程序读取的 1,336 条知识记录 |
| `scripts/build_legal_corpus.py` | 离线重建正式 JSONL，检查源文件哈希及条号连续性 |
| `evals/official_retrieval.jsonl` | 20 条新增法规检索回归题 |
| `evals/traffic_police_retrieval.jsonl` | 30 条公安交管条号、场景和表项检索回归题 |

在项目根目录并激活 `.venv` 后，可用 `ask` 在线提问，再在返回的引用中查看原文。`ask` 需要配置百炼和 DeepSeek 密钥；下方数据校验及默认 BM25 评测在本地执行：

```bash
python -m transport_law ask "湖北省公路路政管理条例第12条"
python -m transport_law ask "公路法第44条"
python -m transport_law ask "行政处罚法第33条"
python -m transport_law ask "道路运输条例第9条"
python -m transport_law ask "湖北省水路交通条例第70条"
python -m transport_law ask "车辆变更车道与后车发生剐蹭"
python -m transport_law ask "道路交通事故处理程序规定第60条"
python -m transport_law ask "湖北道交法实施办法第56条"
python -m transport_law ask "湖北公安交管裁量交通管理册第20项"

python scripts/build_legal_corpus.py --check
python -m transport_law validate-data
python -m transport_law evaluate
python -m transport_law evaluate --dataset evals/official_retrieval.jsonl
python -m transport_law evaluate --dataset evals/traffic_police_retrieval.jsonl
```

本批已进入默认 `LAW_DATA_PATH` 对应文件，不需要重新上传或安装新检索依赖。若 `.env` 自定义了 `LAW_DATA_PATH`，请确认它指向本项目的 `data/processed/legal_chunks.jsonl`。已运行的服务需要重启才能加载新增资料；仅修改 JSONL 不会触发数据热加载。

在线问答使用 BM25、向量检索与 RRF 融合，建议先用“法规名＋条号”核对；自然语言没有命中不表示相关法律不存在。超速、酒驾等已可查相关基础法条，但这不代表处罚法源链、刑事规则或具体案件条件已齐备。三套开发题集只验证检索，不代表真实问答准确率，本次未请求真实 DeepSeek 生成答案。
