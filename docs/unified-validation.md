## 真实在线链路

通过 FastAPI TestClient 执行真实 `/api/v1/ask`，调用百炼与 DeepSeek。上传库强制使用新建空临时目录；只使用仓库内公开法规，没有向模型发送用户上传资料。上传资料的合并流程由上述隔离测试验证。

| 示例 | 观察结果 |
| --- | --- |
| 开车时接了一个电话会怎么处理？ | `answered`，引用道路交通安全法实施条例第六十二条；没有编造本次依据未包含的罚款或记分 |
| 湖北普通公路无许可挖沟埋管、面积大约20平方米，处罚裁量依据及待核事实 | `answered`，引用国家法条、湖北地方条文和裁量表，返回事实补问；没有输出确定的个案罚款 |
| 武汉明天的天气和气温 | `insufficient_evidence`，无引用和编造答案 |

各回答引用均逐条通过 `/articles` 回查，并核对其属于 `/documents` 返回的相同文档、相同版本原文。完整本地响应保存在 Git 忽略的 `data/local/validation/unified_online_live_20261105.json`，不是公开发布物。

联调曾发现无关候选被扩展成回答、并列规定被误述为处罚先后程序，已补充提示词约束并重测。最终电话示例只引用直接相关条文；裁量示例仍偏长。提示词不是法律解释正确性的保证，引用 ID 校验也不能验证语义支持、现行效力或个案适用。下一步应独立评测口语召回的完整性、回答相关性和法律解释，而不能仅统计有无引用。
